# Прогнозирование исхода цирроза печени
Проект по предсказанию клинического статуса пациента с циррозом печени (выживание, пересадка, летальный исход) на основе биохимических анализов крови и данных анамнеза.

## Цель проекта
Построить модель машинного обучения, способную предсказать клинический статус пациента с циррозом печени по результатам биохимических анализов и анамнезу.

## Задачи проекта
1. **Уточнение цели:** Сформулировать более конкретно цель исследования и определить ключевые метрики эффективности моделей.
2. **Исследование и очистка (EDA):** Провести первичный анализ признаков, выявить закономерности, проанализировать аномалии и обработать пропуски.
3. **Подготовка данных:** Выполнить кодирование категориальных переменных, стандартизацию числовых шкал и Feature Engineering.
4. **Моделирование:** Разбить выборку на обучающую и тестовую, обучить пул моделей машинного обучения и настроить их гиперпараметры с помощью кросс-валидации.
5. **Оценка результатов:** Провести сравнительный анализ качества моделей, оценить их обобщающую способность и интерпретировать важность признаков.
6. **Отчетность:** Оформить результаты исследования, структурировать репозиторий и подготовить финальную презентацию.
